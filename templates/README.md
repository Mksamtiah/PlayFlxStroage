# PlayFlx Storage Server

Telegram File Sharing with Permanent Links

## Features
- 🤖 Telegram Bot
- 🌐 Web Upload Page
- 📁 Files Gallery
- 🔗 Permanent Links
- ⬇ Direct Download/Stream
- 📱 MX Player & VLC Support

## Setup
1. Fill `.env` with your credentials
2. Deploy on Render.com
3. Set environment variables

## URLs
- Upload: /upload
- Files: /files  
- Show: /show/{id}
- Download: /dl/{msg_id}/{filename}
